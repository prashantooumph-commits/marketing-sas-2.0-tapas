## Journeys (J01 - J20) Coverage Matrix
- **J01**: Business Onboarding -> Company details, goals, tool connection selection, team recommendation, first action dispatch.
- **J02**: Single Employee -> Conversation, starter task, direct editable artifact, contextual approval, outcome history.
- **J03**: Website Builder -> Visual edit, live working contact form test, simulated publish, instant version rollback.
- **J04**: Content Engine -> SEO topic plan -> Article draft -> Graphic asset -> Editorial calendar -> Distribution.
- **J05 (Flagship)**: Comment to Guide -> Post selector, keyword trigger ("GROW"), genuine downloadable PDF resource, recipient simulator, follow invite, separate consent opt-in, CRM lead capture.
- **J06**: Brand Mention -> Web mention triage -> Sentiment review -> Support handoff -> Public resolution.
- **J07**: Outbound Sales -> CSV import with column mapping -> ICP exclusions -> Personalized 3-touch sequence -> Reply triage -> Meeting booked.
- **J08**: Inbound Speed-to-Lead -> Contact form submit -> Instant qualification -> Calendar booking -> Outbound pause sync.
- **J09**: Meta Ads Launch -> Ad copy & audience selection -> Budget approval -> Launch simulation -> Creative optimization review.
- **J10**: Google Search Campaign -> Intent keywords & negatives -> Landing page test -> Budget simulation.
- **J11**: Lifecycle Messaging -> Segment filter -> Email & WhatsApp templates -> Opt-out handling -> Scheduled dispatch.
- **J12**: Retargeting / Reactivation -> Dormant client filter -> Privacy-safe reactivation offer -> Conversion check.
- **J13**: SEO & Answer Engine -> Baseline visibility check -> Content gap recommendation -> Experiment variant -> Measured result.
- **J14**: Webinar / Event Launch -> Registration landing page -> Email sequence -> Attendee status simulation -> Follow-up.
- **J15**: Commerce & Cart Recovery -> Catalog item inquiry -> Checkout preview -> Simulated payment & order confirmation.
- **J16**: Referral Program -> Partner brief -> Unique tracked link -> Referral event -> Payout approval review.
- **J17**: Commercial Proposal -> Scope & fee table -> Legal review signoff -> Client mock decision -> Deal signed & onboarding trigger.
- **J18**: Confidential Ops / HR / Legal -> Internal NDA redline -> Candidate interview notes -> Private coach isolation check.
- **J19**: Shared Knowledge Learning -> Feedback on output -> Proposed guideline update -> Approval -> Rollback mechanism.
- **J20**: Multi-Tenant & Settings -> Switch between Cedar & Co Learning and Acme Craft Goods -> Plan tier switcher -> Export local JSON -> Safe reset.
